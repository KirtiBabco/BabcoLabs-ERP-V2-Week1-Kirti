# Project 1 — Business Record API

Purpose: prove a relational ERP-style business object through REST + validation + Azure SQL.

Minimum evidence:
- normalized parent/child tables;
- PK/FK/uniqueness constraints;
- POST/GET/filter/PATCH behavior;
- predictable 400/404/409 errors;
- accepted records survive service restart.

Implementation starts only after Build Units 0.1-0.3 are verified.
